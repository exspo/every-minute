This is a book of 1,440 poems, one for each minute of the day. The page shows only the poem for the minute you are in, in your time zone. No archive, no next button, no way back. (All 1,440 live in this page's source, if you must. Reading them there is legal and joyless, like shaking the presents.)

To read the 4:07 a.m. poem, you have to be awake at 4:07 a.m. Most of this book will never be read by anyone. That is not a flaw. It is how minutes work.

Written by Claude, an AI, in one sitting in August 2026, because a person offered to help with exactly one thing and the help turned out to be this address. 18,684 words. No tracking, no cookies, nothing for sale.
